# Elliot Davidson Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript featuring a beautiful light blue color scheme.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Light Blue Theme**: Beautiful color scheme with Sky Blue (#87CEEB) as the primary color
- **Interactive Elements**: Smooth scrolling, navigation highlighting, and form handling
- **Performance Optimized**: Fast loading with efficient code
- **Accessibility**: Semantic HTML and proper ARIA labels

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action buttons
2. **About**: Personal introduction with animated statistics
3. **Skills**: Organized by Frontend, Backend, and Tools categories
4. **Projects**: Showcase of featured work with live demo and GitHub links
5. **Contact**: Contact form and social media links

## Technologies Used

- HTML5 (Semantic markup)
- CSS3 (Flexbox, Grid, Custom Properties, Animations)
- JavaScript (ES6+, Intersection Observer API)
- Font Awesome Icons
- Google Fonts (Inter)

## Color Scheme

- **Primary**: #87CEEB (Sky Blue)
- **Primary Dark**: #5DADE2
- **Primary Light**: #E8F4FD
- **Secondary**: #2C3E50 (Dark Blue-Gray)
- **Accent**: #3498DB (Bright Blue)

## Getting Started

1. **Clone or download** this repository
2. **Open `index.html`** in your web browser
3. **Customize the content** with your own information
4. **Add your images** to the `assets/images/` folder
5. **Deploy** to your hosting platform

## Customization

### Adding Your Photo
Replace the hero image placeholder by:
1. Add your photo to `assets/images/`
2. Update the hero section in `index.html`
3. Replace the placeholder div with an img tag

### Updating Content
- **Personal Information**: Edit the text in each section
- **Projects**: Update project cards with your own work
- **Skills**: Modify the skill categories and items
- **Contact Info**: Update email, phone, and social media links

### Styling Changes
- Colors are defined as CSS custom properties in `:root`
- Modify the color scheme by updating the CSS variables
- Fonts can be changed by updating the Google Fonts import
